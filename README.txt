Краткое описание:
Training Planner — это настольное приложение на Python с графическим интерфейсом (GUI), предназначенное для ведения дневника спортивных тренировок. Программа позволяет сохранять информацию о дате, типе активности и длительности занятий.
Основные возможности:
Добавление данных: Быстрая запись тренировки с автоматической подстановкой текущей даты.
Хранение: Все данные сохраняются в файл trainings.json в удобном текстовом формате.
Фильтрация: Поиск и фильтрация записей по типу тренировки и дате в режиме реального времени.
Валидация: Проверка корректности ввода даты и числовых значений.

Инструкция по запуску:
1. Требования
Для работы программы необходим установленный интерпретатор Python версии 3.x.
В коде используются стандартные библиотеки Python (tkinter, json, os, datetime), поэтому установка дополнительных внешних пакетов через pip не требуется.
2. Как запустить
Скопируйте код программы в файл и сохраните его под названием planner.py.
Откройте терминал (командную строку).
Перейдите в папку с файлом.
Выполните команду: bash

Примеры использования и работы:
Добавление первой тренировки:
При запуске поле «Дата» уже заполнено сегодняшним числом (например, 05.05.2024).
В поле «Тип» введите: Бег.
В поле «Длительность» введите: 45.
Нажмите кнопку «Добавить». Запись мгновенно появится в таблице снизу.
Поиск записей:
Если у вас накопилось много записей, введите слово Силовая в поле фильтра «По типу».
Таблица автоматически обновится и покажет только силовые тренировки.
Аналогично можно фильтровать по месяцу или году, введя, например, .2024 в поле фильтра «По дате».
Сохранение прогресса:
Вы можете закрыть программу в любой момент. При следующем запуске все ваши данные будут автоматически подгружены из файла trainings.json, который создастся в той же папке.
